# 复核工作台改版 / Review workspace build

本地改版标识：`review-workspace-20261117`。基于 v0.6.15 和 AI 布局 Beta，未作为上游正式版本发布。旧交付保持独立。

## 使用

- 直接打开交付中的单文件 HTML。右上角 **⚙ 设置** 配置 HTTPS 接口、视觉模型和密钥，布局校正与 Marker 共用一份配置。配置无需先导入图片。密钥默认仅在当前页面内存中；勾选记住才会在当前浏览器本地明文保存。
- **AI 有带泳道校正与计数** 和 **AI Marker · 复核** 打开主界面内的工作区，不创建新浏览器窗口，也不以模态遮罩覆盖主界面。右上角返回、Escape 均可收起；关闭或切换任务会取消尚未完成的请求。
- 布局工作区支持滚轮 / 双指缩放，空白处拖动平移，或开启“平移”。放大、缩小与适应按钮始终可用。拖动橙色四角；选中角点后，方向键移动 1 个分析图像素，Shift + 方向键移动 10 像素。蓝色框可整体移动和逐角调整；图像中的选中泳道与复核列表联动。
- 原图与校正结果可切换查看。AI 原始定位编号保留，删除误定位后其余编号不重编；手动补框以 M 编号区分。分类、坐标、增删操作可在复核工作区内撤销 / 重做，不改变主项目。
- 底部固定显示保留、空道剪除和不确定数量。应用前在同一页面内确认将清空名称、分组、条件、标注和 Marker。成功应用可用主界面单步撤销。原始文件字节保留。
- Marker 的本地 / AI 结果在同一工作区对照。详细发送与应用说明折叠收纳；应用按钮放在每份结果预览上方。人工确认、排除与剪除的保护规则保留。

## 审阅包与样式

**导出 → 一键导出审阅包（ZIP）** 包含原始文件精确字节、可重新打开的 `.gelfig`、所选格式的最终成图、处理日志、图例说明草稿，以及每个内容文件的 SHA-256 / 尺寸 / 泳道映射清单。成图可选 PNG、TIFF、SVG、PPTX；手机导出面板也有 ZIP 入口。包在本机生成，不自动上传，不代表期刊认证。原图与项目可能包含实验内容。

导出检查统一展示文件 DPI、胶图有效 DPI、胶图物理宽度、完整成图尺寸、字号与饱和 / 显示削顶 / 裁切拼接提示。安全宽度按当前选定的目标 DPI 计算。修复按钮显式修改参数并可撤销；检查本身不调用 AI。原有检查开关继续生效。

**文件 → 导出仅版式模板** 保存命名的字体、字号、线宽、间距、物理宽度规则、显示方式与单位形式，不复制样本名、分组、实验坐标或面板字母。通过既有“载入样式”入口导入，应用前查看摘要。也可将当前版式指定为本浏览器中新图像的实验室默认，或取消该默认。手机的“更多”面板包含相应入口。既有完整实验模板功能继续可用。

## 数据与状态规则

- TIFF 32-bit 整数 Predictor 2 使用逐行、逐通道、按字节序的模 2³² 还原。未支持的 Predictor / 位深 / 样本组合明确拒绝，不静默解码。
- 源数据异步操作按递增代次提交。新导入、打开项目、历史恢复或后一次曝光选择会使旧操作失效；旧解码晚到不会覆盖新项目，也不会结束新操作的忙碌状态。使用可控延迟回归覆盖六种操作交错。
- 曝光撤销同步恢复对应的原始字节、解码灰度 / RGB、曝光索引和派生缓存。访问过的解码源在页面内存中保留，以支持同步撤销；多张高分辨率曝光会增加内存占用。项目文件只包含当前所选原始文件，浏览器历史仍可保存整组曝光。
- 透视先在候选状态计算，成功后提交；失败恢复原状态对象、缓存、选择和历史，新增的临时缓存也会移除。
- 重置基线显式绑定同一个源文件的已采用状态，不依赖某个 AI 字段是否存在。AI 采用时的基线不会在保存重开后被旧的导入识别结果替代。曝光替换时同步绑定新源。
- `lastMarkerAdoption` 与 AI 布局采用快照保留处理来源；`currentSources` 和逐 Marker 的实际来源表示当前结果。布局快照数量是采用时的数量，当前可见数量另列。
- 日志区分原始解码尺寸、分析图尺寸、裁切尺寸和成图点尺寸。原图 SHA 始终对应原始字节。启发式胶类型判断显示为规则判断，不再把内部一致性分值写成准确率。
- 校正预览直接按显示尺寸采样；最终应用仍使用完整分辨率。缩放 / 平移只改变视口，不重新识别、不修改图像坐标。

## 开发和验证

保持纯静态脚本、无新增运行时依赖、支持 `file://` 和单文件构建。

```
node scripts/check-updates.mjs
node scripts/bundle-onefile.mjs
npm test
```

`npm test` 包含原有完整套件、新工作区交互、独立 TIFF 像素、曝光恢复、透视失败回滚、来源追踪与四种审阅包回归。`tests/backup-outputs.cjs` 在测试覆盖已存在输出之前创建并核验唯一备份，备份在源码目录外的 `generated-backups` 中。

测试仅使用合成图和被拦截的 AI 响应。没有真实视觉服务准确率、真实手机或原生 PowerPoint 的新增验证。完整多文件批处理、定量、背景扣除、曲线拉直和条带修补不属于本轮改版。

## English

This local build moves shared vision-API settings to the top-right header and places correction and Marker review inside the main application stage. Layout review provides zoom, pan, pinch, pixel nudges, editable lane boxes, stable IDs, local review undo and a persistent action footer. API requests remain explicit and use the user's configuration; there are no retries or provider switches.

Core fixes cover exposure history/source consistency, 32-bit integer TIFF horizontal prediction, stable lane-list bindings and atomic perspective application. Logs distinguish original/analysis/figure dimensions and historical adoption from current sources. Local review ZIPs include exact originals, a reopenable project, a chosen final figure, processing records, draft disclosures and hashes. Named appearance-only presets and lab defaults avoid copying experimental content. Validation uses synthetic images and intercepted responses, not real-model accuracy measurements.
