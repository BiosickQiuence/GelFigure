# AI 泳道校正与计数 v1.1.0

本说明对应 BiosickQiuence/GelFigure v1.1.0 的 AI 泳道复核界面。请在此界面复核识别建议后再应用。全自动页面可在导入图片、选择 Marker 后自行扩展过小的四角，接着完成标记。两种方式共用右上角的 API 设置。

## 使用

1. 导入胶图，先用原有旋转／镜像把泳道大致摆成竖直方向。
2. 在 **泳道对齐 → AI 泳道校正与计数** 打开试验窗口。
3. 点“接口设置（沿用 Marker）”填写视觉接口、模型和密钥。本版本中的 Marker 与布局共用这套配置；项目不携带密钥。普通本地处理和手动四点仍可离线运行。
4. 主动点 **发送图像识别布局**，发送当前几何处理后的完整分析图 PNG 副本，有原色即保留原色。只附加图像尺寸、颜色信息、当前胶类型和任务说明，不附加文件名、泳道名、条件、分组、标注、项目、Marker 库或缓存。
5. 核对预览：绿色为有带泳道，灰色为空道，橙黄色为不确定泳道；不确定默认保留。橙色四角可拖动，青色四边形是实际采用的裁切范围。右边显示真正的校正和空道剪除预览。
6. 可调整四角、像素边距、每道分类及泳道框；误定位可删除，漏定位可用“手动新增泳道框”在输入预览拖框补上。补框和分类修正会标为人工调整。AI 声称的数量与当前定位列表不一致时会提示，不补造缺失的位置。
7. 点 **应用 AI 校正与泳道** 后确认提示。应用会重建泳道、清空现有名称／条件／分组／标注及 Marker 校准，回到主界面；可用一次撤销完整恢复。建议先保存项目副本，并先做布局、再做命名和 Marker 标注。
8. 校正后若需要 Marker 大小，继续使用 AI Marker 或手动指定。布局应用本身不会自动调用 Marker API，也不会把 AI 泳道位置吸附到本地算法。

## 有带区域和空泳道

- AI 四角用于确定透视平面；实际裁切会进一步依据 **有带及不确定泳道框的包围范围** 收紧，包含合理边距，排除边缘空道和上下空白，不直接采用整块胶的外轮廓。
- 边距可手调 0–50 像素。四角或泳道框不合法、重合、超出图像，或剪除空道会压住有带框时，不能应用，需先修正。
- 中间空泳道不能通过一个四边形单独挖掉，因此校正分析图保留真实相邻关系；**成图使用原有整道剪除功能移除中间空道，并明确保留拼接间隙／线**，不把它伪装成连续原图。
- 当前主界面的“泳道数”包含校正范围内已剪除的物理槽位；Beta 同时列出有带数、不确定保留数、边缘裁去数、中间剪除数及成图实际保留数，便于比较。
- 若 AI 未定位某条空道或漏掉弱带，需要在预览中人工修正。没有确认有带泳道、没有可靠四角或请求失败时，不会强制改成整胶校正，也不会自动换服务、模型、代理或本地算法。

## 数据和保存

实际校正复用原版四点透视和双线性采样，从解码原图重采样，不从上次校正图重复取样。RGB 和灰度使用相同的几何；原始文件字节和 SHA-256 保留。

AI 提案及预览图仅留在本页面内存。项目仅保存采用的四点、泳道中心和显示状态、必要来源与分类数量；不保存原始 API 回复、图像请求、接口地址、模型配置或密钥。本轮 Beta 采用后的项目／历史以已采用状态作为重新打开后的重置基准；原文件可通过“导出原始数据”取回，或在当前页面撤销布局操作。

布局请求的 HTTPS、CORS、90 秒超时、2 MB 响应限制、32 MB 上传副本限制、拒绝重定向及密钥可选记忆规则与 AI Marker 相同。仅在主动点击时请求，失败明确报错，不重试或切换。修改项目或接口设置时，旧请求会取消，旧结果不能覆盖新项目。

## 实验协议

Chat Completions 图像消息要求返回 JSON：

```json
{
  "schema_version": 1,
  "image": {"width": 1000, "height": 700},
  "plane_quad": [{"x":0.1,"y":0.1},{"x":0.9,"y":0.1},{"x":0.9,"y":0.9},{"x":0.1,"y":0.9}],
  "lane_count": 1,
  "lanes": [{"status":"active","quad":[{"x":0.3,"y":0.2},{"x":0.4,"y":0.2},{"x":0.4,"y":0.8},{"x":0.3,"y":0.8}]}]
}
```

四角均为左上、右上、右下、左下；坐标相对于整张上传图归一化，像素为 `coordinate * (dimension-1)`。分类为 `active`、`empty`、`uncertain`；`plane_quad` 和 `lane_count` 在不能确定时允许为 null。泳道 quad 应围住该泳道的实际条带宽度和上下跨度。空道可以在有带平面之外。

这是可试验的客户端流程，不保证视觉模型在真实斜拍、弱带、反光或严重畸变图上的分类和角点准确性；数量一致也不证明识别正确。真实效果需要使用你的接口和胶图核对。本次验证使用合成图与模拟回复，不声明真实识别准确率提高，也不声明恢复了真实物理长宽比。
