使用说明与快捷帮助

· API 配置教程

在手机上

  • 底部切换原图 / 成图 / 设置，右下角是导出；顶部可撤销 / 重做，更多菜单里有打开、保存项目和语言。
  • 原图：双指缩放、拖动。点泳道线或泳道号选中，底部可微调、剪除、删除；双击已有 Marker 泳道打开编辑，普通泳道双击不操作，新增请点“+ 泳道”。拖红框改出图范围，拖黄线修正 Marker 条带。Marker 面板可按住标题拖动移开。
  • 成图：点灰色泳道号输入名称，键盘上的“下一项”跳到下一条；小字看不清点“放大”。分组横线：依次点首尾两个泳道名。
  • 导出：PNG 生成后长按图片即可存到相册或发给朋友；“分享 / 存储”可以把任何文件存到“文件”或发到其他 App。
  • 在微信里打开时无法下载文件：点右上角 ··· 选择“在浏览器打开”。

离线使用：只下载一个文件

下载 GelFigure-v1.4.0.html，保存到电脑，双击用浏览器打开即可。不用安装、不用解压。仓库里的 index.html 单独下载不包含完整工具。

顶栏或“更多 → 历史项目”可打开本浏览器缓存的图片和编辑进度，包括全部曝光。支持改名、删除，恢复时不会重新识别；导入下一张图会保留上一张的进度。清理浏览器数据会清除缓存。

备份或换电脑时，请用“更多 → 保存项目”。.gelfig 保存当前曝光的原图和标注，其他曝光的原文件请另行保留。缓存失败时，建议先保存项目文件再切换图片。

最快的出图方式

需要 AI 处理时，在设置里保存接口配置，打开“AI 全自动处理”。拖入一张胶图并选择 Marker 型号，程序会校正泳道、标记条带，并打开可编辑的成图。

  1. 拖入胶图 —— 转正、裁切、泳道、Marker、对比度全部自动完成。同一块胶的多张曝光可以一起拖进来，自动挑最好的一张。
  2. 在右侧成图上点泳道名输入，回车自动跳到下一条；也可用成图上方的“批量粘贴”一次填入整行。
  3. 选 Marker 泳道和型号，点“识别此泳道”；“校准 / 图例”在原图旁打开小型参考卡。
  4. 右上角"导出 PNG"。导出前会自动检查常见问题。

常用操作

  • 只出一部分泳道：直接在原图上拖红框，裁切保留泳道名称和 Marker 选择。
  • 剪掉中间某条泳道：在原图上选中后按 H（或取消"显示"），会自动加拼接间隙，图注中需说明。
  • 分组横线：在成图上从一个泳道名拖到另一个泳道名。
  • 目标条带箭头：点"目标条带"，再点那条带；大小按 Marker 估算，超出 Marker 范围会标 ≈。
  • + / − 条件行：加一行后，在成图上点格子即可在 + / − / 空 之间切换。
  • 泳道线没对齐：在左侧填写条数（手机在“设置”页），拖首尾线，中间实时均分；拖中间线可整体平移。关闭“等距联动”或按 Alt 拖动可单独微调。数量包含 Marker 和空道，修改可撤销。
  • 重新识别：“框内重新识别泳道和 Marker”一次完成两个步骤，保留手动确认的 Marker 和定位点，不重新添加已取消的 Marker；单纯拖裁切框不会重新分类。
  • 字号 / Marker 显示：成图上方“字体与字号”统一设置，也可点 Marker 数字或双击原图中已有的 Marker 泳道；面板可按住标题拖动移开。支持显示、隐藏和删除且不会自动收起。隐藏仍保留校准，删除同时移除定位点；可撤销或重新定位恢复。
  • 泳道名旋转：点成图上方“泳道名角度”。默认自动沿用原有排版规则；可选预设、拖动滑块或输入 0–90°，对所有泳道名生效。选回“自动”即可恢复，角度会随项目、样式和导出保存。
  • 单个名称与局部格式：点泳道名，选中文字可设正体、斜体、上标、下标；未选中则作用于整段，再点一次上/下标可恢复基线。“清除格式”恢复统一字形，输入时可用 Ctrl/⌘+Z 撤销。默认统一字号与角度，按需开启“此泳道单独设置”，取消勾选即可恢复统一。
  • 区域框：在原图上拖出矩形，可选在成图旁放大展示。侧边括号：在原图上拖过一段区域（拖尾、多聚体）。侧边文字：染色方法、抗体、曝光时间，放在胶图侧边或下方；可拖动（或用位置滑杆）沿胶边移动，避开其它文字。目标条带也可标成 *（非特异条带）、# 或 †。
  • Marker 条带不对：选好泳道和型号后点“识别此泳道”，只对齐这一个 Marker。打开“校准 / 图例”，先选大小再点原图上的实际条带，也可先点条带再选大小；拖黄线微调，Alt 关闭吸附。参考卡里切换型号先预览，点“使用此型号”才应用。图例仅作示意；未匹配到的预测条带默认隐藏。
  • 旋转：标注会跟着图一起转；可打开参考网格目测。

图像规范

  • 只做全图线性调整；Gamma 默认锁定为 1。
  • 区分相机过曝（只能重拍）和色阶削顶（可调回）。
  • 剪除泳道会自动加拼接分隔；不同凝胶不可拼进同一面板。
  • 建议同时导出"未裁切图"和"原始数据"放补充材料。
